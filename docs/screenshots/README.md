### How to capture:
1. Run the lab in EDA Playground or GTKWave
2. Zoom the waveform so all inputs/outputs are visible
3. Use Snipping Tool (Windows) / gnome-screenshot / Cmd+Shift+4 (Mac) to capture
4. Save PNG here with a descriptive name
5. Reference it in a markdown file:
   ```markdown
   ![Caption](docs/screenshots/file.png)
   ```
